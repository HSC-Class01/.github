## 프로젝트 목표

1. AI 윤리에 중요한 가치를 두며, 프로젝트 참여 학생 모두 UNESCO의 AI 윤리 과정을 수료했습니다.

3. 공공 데이터를 활용해 Analytics AI Agent를 만들고 분석 보고서를 작성합니다.

## 소개

HSC-Class01은 기업과 산업에 관한 데이터를 분석하고 프로젝트 결과를 정리하는 학습 공간입니다. 공개 데이터를 수집·정리하고, 재무 분석이나 대시보드와 같은 결과물로 구현합니다.

각 저장소에는 프로젝트 목적, 사용 방법, 데이터 출처와 분석 범위를 기록해 학습과 협업에 활용합니다.

## 프로젝트 이용 안내

1. 관심 있는 저장소를 선택하고 `README`에서 프로젝트 목적과 실행 방법을 확인합니다.
2. 데이터 출처, 수집 기간, 분석 범위와 한계를 확인합니다.
3. 필요한 API 키는 저장소의 GitHub Actions Secrets에 등록하고, 코드나 문서에 직접 공개하지 않습니다.
4. 질문이나 개선 의견은 해당 저장소의 `Issues` 또는 Pull Request를 이용합니다. 저장소에서 해당 기능이 활성화되어 있는지 먼저 확인해 주세요.

## 함께 지키는 원칙

- 데이터와 분석 결과의 출처를 기록합니다.
- 확인되지 않은 값은 임의로 채우지 않고, 한계와 누락을 명확히 표시합니다.
- API 키, 비밀번호, 개인 정보 등 민감한 정보를 공개 저장소에 올리지 않습니다.
- 프로젝트 결과는 학습과 정보 제공을 위한 것이며, 투자 판단 전에는 원자료와 최신 공시를 확인합니다.
